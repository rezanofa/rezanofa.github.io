Tentang aplikasi

"rakitilmu rclone" adalah alat internal yang dipakai oleh pemilik ilmurakit.my.id untuk mengunggah dan mengelola file konten (video, naskah, laporan) di Google Drive milik pemilik sendiri. Aplikasi ini tidak ditujukan untuk publik.

Data yang diakses

Aplikasi hanya mengakses Google Drive akun yang memberi izin, untuk membaca, membuat, dan memperbarui file hasil produksi konten. Data Google pengguna tidak dijual, tidak dibagikan ke pihak ketiga, dan tidak dipakai untuk iklan.

Penyimpanan

Token akses disimpan secara aman di server pribadi pemilik dan dapat dicabut kapan saja melalui pengaturan izin akun Google.
